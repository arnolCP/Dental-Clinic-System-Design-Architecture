Este proyecto corresponde al backend del sistema clínico, desarrollado con **python** y **Django**.  
Permite la gestión de usuarios, inicio de sesión, registro y panel de administración.

---

## Requisitos previos


## Abrir la carpeta [backend] en la terminal

Crear el entorno virtual:

python -m venv venv

Prender el entorno virtual:

/venv/Scripts/Activate

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- [requirements.txt)

Para instalar:

pip install -r requirements.txt


## Para ver el proyecto

python manage.py runserver
